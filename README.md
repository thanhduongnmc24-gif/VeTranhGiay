# VeTranhGiay

Ung dung ve tranh native cho iPad, dung UIKit va PencilKit.

## Cach build

1. Dua toan bo ma nguon len nhanh `main` cua GitHub.
2. Mo tab `Actions`.
3. Chon workflow `Tao IPA khong ky`.
4. Bam `Run workflow`.
5. Tai `VeTranhGiay.ipa` trong Artifacts hoac Releases.
6. Ky IPA bang ESign roi cai len iPad.

## Luu y

- Ung dung yeu cau iPadOS 16 tro len.
- IPA do GitHub tao la IPA chua ky.
- Lan dau luu tranh, iPad se hoi quyen them anh vao album.
- Ban ve goc duoc tu dong luu trong ung dung de mo lai va ve tiep.
